# Simulador de Taxis - Salta

Proyecto desarrollado para la materia **Algoritmos y Estructuras de Datos** de la Universidad Nacional de Salta.

El proyecto consiste en un simulador de viajes en taxi basado en un **grafo dirigido** que representa calles e intersecciones de la ciudad de Salta.

## Características

- Representación de la ciudad mediante un grafo dirigido.
- Cálculo de caminos mínimos mediante Dijkstra.
- Uso de una cola de prioridad para seleccionar taxis.
- Simulación de pasajeros y taxis.
- Cálculo de distancias mediante Haversine.
- Interfaz gráfica desarrollada con JavaFX.
- Uso de estructuras de datos implementadas durante la materia.
- Visualización de los taxis y pasajeros sobre un mapa.

## Tecnologías

- Java
- JavaFX
- GeoJSON
- CSV
- Algoritmos y estructuras de datos
